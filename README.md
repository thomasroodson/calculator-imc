# BMI Calculator

A small React application that calculates Body Mass Index (BMI) from a person's height and weight, then displays the corresponding classification.

I built this project while studying React and TypeScript. It was a practical exercise in managing form state, validating user input, separating calculation logic from the interface, and rendering different result states.

## Features

- Enter height in meters and weight in kilograms
- Calculate BMI from the submitted values
- Display a result classification
- Return to the form and calculate again
- Responsive interface built with CSS Modules

## Tech stack

- React
- TypeScript
- Vite
- CSS Modules

## Run locally

```bash
npm install
npm run dev
```
